# Интерактивные архитектурные диаграммы

Создавай не картинку, а обозреватель модели: компактный граф, устойчивую навигацию
и подробности выбранного элемента. Разделяй содержание, раскладку и представление.

## Основные решения

- Используй React Flow для интерактивного canvas и собственных React-узлов.
- Используй ELK Layered для направленных процессов, узлов разного размера и
  ортогональной маршрутизации. Не расставляй крупные графы ручными координатами.
- Храни описание узлов и связей в типизированной модели, а не внутри JSX или SVG.
- Большую предметную область дели на несколько связанных представлений. Общий
  экран должен объяснять систему, а не показывать каждую техническую ветвь.
- Показывай выбранный элемент в постоянной панели: ответственность, предусловия,
  исходы, ошибки, повторную проверку, настройки и ссылки на код/ADR.
- Сохраняй работоспособность без сети: не используй CDN. Если нужен автономный
  файл, собирай зависимости внутрь HTML; исходники и сборку храни раздельно.
- До появления раскладки показывай нейтральный loading state. Никогда не оставляй
  DSL или исходный код видимым до клиентского рендеринга.

## Рабочий процесс

1. Изучи фактическую структуру проекта, README и ADR; не придумывай связи.
2. Определи аудиторию, набор представлений и уровень детализации.
3. Сначала зафиксируй типизированную модель узлов, затем настрой ELK и только после
   этого стилизуй React-компоненты.
4. Добавь выбор узла, правую панель, поиск, fit-to-view, масштабирование, мини-карту
   для широкого экрана и доступную клавиатурную навигацию.
5. Обеспечь спокойный дизайн: ясная иерархия, ограниченная палитра, короткие
   подписи, отсутствие декоративного шума и умеренная анимация.
6. Собери production-артефакт и проверь его тем способом, которым воспользуется
   владелец, включая автономное открытие при заявленной поддержке.
7. Визуально проверь каждый вид на широком и узком экране. Не создавай коммит,
   пока владелец не одобрил результат, если он попросил предварительную проверку.

Для схемы данных, параметров ELK и критериев готовности прочитай
