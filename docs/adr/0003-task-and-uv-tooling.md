# ADR-0003: кроссплатформенные команды Task и окружение uv

- Статус: принято
- Дата: 2026-09-10

## Контекст

Прежние инструкции напрямую вызывали Python из Windows-окружения и повторяли
длинные наборы CLI-флагов. На Linux путь к интерпретатору отличался, а изменение
одного режима требовало синхронно исправлять несколько примеров в README.

Проекту нужен короткий одинаковый интерфейс для локальной машины, VPS и CI, но
существующий Python CLI должен остаться канонической точкой исполнения и сохранить
обратную совместимость.

## Решение

Использовать два независимых слоя:

1. `uv` управляет Python 3.12, `.venv`, разрешением зависимостей и `uv.lock`.
2. Task читает `Taskfile.yml` и предоставляет именованные команды установки,
   запуска, проверки и сборки.

Taskfile остаётся тонкой оболочкой. Он не реализует бизнес-логику и вызывает
установленную точку `hh-resume-raiser` с существующими CLI-флагами. Общие значения
профилей объявлены один раз переменными Task. Дополнительные аргументы передаются
исходному CLI после `--`.

Основные пользовательские команды:

- `task install`;
- `task init-session`;
- `task raise` и `task raise-ui`;
- `task activity` и `task activity-ui`;
- `task full-activity` и `task full-activity-ui`;
- `task check` и `task build`.

Пользовательские данные остаются в исключённых из Git INI-файлах. Taskfile хранит
только безопасные пути по умолчанию и параметры режимов, но не учётные данные.

## Рассмотренные альтернативы

### Make

Отклонён как основной интерфейс: на Windows он обычно отсутствует, а рецепты часто
неявно зависят от Unix shell и утилит. Makefile можно добавить позднее лишь как
необязательный адаптер к тем же задачам.

### Отдельные PowerShell- и shell-скрипты

Отклонены из-за дублирования логики и необходимости поддерживать два варианта
каждой команды.

### Just

Подходит для коротких команд, но выбор и настройка shell на Windows добавляют
платформенную ветвь, которую Task закрывает встроенным интерпретатором.

### Poe the Poet

Хорошо интегрируется с Python, однако сам становится доступен только после
подготовки Python-окружения. Для внешней команды начальной установки удобнее
независимый бинарный Task.

## Последствия

- Команды README одинаковы на Windows, Linux и macOS.
- `uv.lock` делает установку зависимостей воспроизводимой между платформами.
- Длинные флаги скрыты за понятными именами режимов, но остаются доступными для
  диагностики и обратной совместимости.
- Для начала работы пользователь один раз устанавливает `uv` и Task.
- Минимальному Linux-серверу может отдельно потребоваться
  `task install-system-deps` с системными правами.
- Изменения режима необходимо вносить в Taskfile и проверять через сухой запуск
  Task, не копируя набор флагов в README.
