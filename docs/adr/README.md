# Architecture Decision Records

ADR фиксируют существенные архитектурные решения проекта: исходную проблему,
рассмотренные варианты, принятое решение и его последствия. Принятые записи не
переписываются задним числом; изменение решения оформляется новым ADR со ссылкой на
предыдущее.
