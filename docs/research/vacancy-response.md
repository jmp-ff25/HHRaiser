# Исследование отклика на вакансию

## Назначение и исходная страница

Сценарий отправляет отклик только на подходящую вакансию без обязательных данных. Исходная
страница — публичная карточка `https://hh.ru/vacancy/<ID>` после подтверждённого входа.

## Предусловия

- владелец явно включил отклики;
- вакансия прошла поисковые фильтры и порог соответствия;
- содержательный просмотр завершился успешно;
- по публичному ID ещё нет результата отклика в локальной истории.

## Наблюдаемое состояние до действия

На исследованной карточке доступна кнопка с ролью `button` и именем «Откликнуться».
Стабильный атрибут верхней кнопки — `data-qa="vacancy-response-link-top"`. Её `href`
позволяет заранее отличить внутренний путь HH от внешнего сайта. В текущем исследовании
авторизованная форма после клика не отправлялась, поэтому неизвестные варианты интерфейса
обрабатываются консервативно.

## Устойчивые локаторы

1. `get_by_role("button", name="Откликнуться", exact=True)`;
2. `[data-qa="vacancy-response-link-top"]`;
3. `[data-qa="vacancy-response-submit-popup"]` для финальной кнопки формы;
4. `[data-qa="vacancy-response-success"]` и
   `[data-qa="vacancy-response-link-view-topic"]` для подтверждения;
5. семантические обязательные `input`, `textarea` и `select` внутри формы.

Координаты, `nth-child`, визуальные классы и хрупкие XPath не используются.

## Сетевые сигналы

Перед нажатием читается публичное описание `GET https://api.hh.ru/vacancies/<ID>`.
Поля `has_test`, `response_letter_required`, `relations` и внешний `response_url` служат только
причиной заранее остановиться. URL хранится без query-параметров; тела ответов,
заголовки авторизации, cookies и токены не записываются.

Описание этих полей: [официальная документация HH API](https://api.hh.ru/openapi/redoc#tag/Vakansii/operation/get-vacancy).

## Подтверждение успеха

Успех фиксируется только если HH показывает видимый признак «отклик отправлен» или
«вы откликнулись». Сам клик, HTTP-ответ или переход на другую страницу успехом не
считаются.

## Ошибки и неизвестный результат

Анкета, тест, обязательное письмо, выбор резюме, форма входа, обязательные поля и внешний
сайт получают статус «требуется участие кандидата». Автоматический отклик на эту вакансию
пропускается, после чего общий цикл переходит к следующей вакансии. Потеря страницы —
техническая ошибка. Если после одного безопасного действия нет ни подтверждения, ни
распознанной формы, результат считается неизвестным.

## Повторная проверка и вмешательство владельца

Автоматический повтор для вакансии не выполняется: неизвестный исход мог фактически
оказаться успешной отправкой. Владелец открывает ссылку из Excel-журнала и вручную
завершает анкету, письмо, тест, внешний отклик либо проверяет неизвестный результат.
