# Диаграммы HHRaiser

Документация разделена на два уровня, чтобы схемы оставались компактными:

- `overview.svg` — обзор полного непрерывного цикла;
- `vacancy-flow.svg` — подробный отбор, оценка и повторный допуск вакансий.

Готовые SVG открываются обычным браузером и не требуют PlantUML, Java или доступа
к интернету. `vacancy-flow.svg` — компактная схема текущего платного отбора;
`vacancy-flow.puml` содержит расширенную версию потока для доработки в PlantUML.

Для генерации SVG из расширенной версии установите PlantUML 1.2026.6 или новее
и выполните из корня проекта:

```powershell
plantuml -tsvg -charset UTF-8 docs/diagrams/overview.puml docs/diagrams/vacancy-flow.puml
```

Обзор использует стандартную раскладку PlantUML/Graphviz, а детальная схема —
встроенный движок Smetana для стабильного расположения горизонтальных этапов.
Официальная native-сборка PlantUML для Windows уже содержит всё необходимое;
при использовании JAR на другой платформе для обзорной схемы установите Graphviz.
